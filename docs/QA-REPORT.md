## 已知限制（交付時告知）
- 在 LINE 內建瀏覽器中，CSV 下載可能被擋；已在畫面提示改用外部瀏覽器開啟。
- 機器人推播（從外部瀏覽器記帳時）會消耗官方帳號每月免費訊息額度；在群組內開啟則不消耗。
- LIFF 在正式環境的登入、`sendMessages`、`shareTargetPicker` 需在實機 LINE 上驗證（本環境無 LINE 帳號），已以示範模式與模擬測試覆蓋其餘邏輯。
